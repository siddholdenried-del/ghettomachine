Most controls work the same in the browser and on the FM-1. Sound output, storage, WAV transfers and firmware updates do not. Check which version you're using before you reset, move or save anything important.

Browser controls that replace physical gestures

Open the browser groovebox, choose Switch on, then press the on-screen PLAY / STOP button. Switching on starts audio processing; it is not the transport. The front panel needs focus for its single-key shortcuts.

MIDI clock, external playing and sounds per pattern

From the HOME scene grid press HOME again for SONG, then again for SETUP.

  • K1 MIDI CLOCK: OFF uses the internal clock without clock routing. SEND outputs 24 clocks per beat plus transport start/stop over USB-MIDI. FOLLOW uses the external tempo and start/stop, and begins on the first clock after Start. Only one unit should be clock master. FOLLOW is not sample-accurate; allow a few milliseconds and check alignment by ear.
  • K2 SOUNDS: SHARED uses one sound per track across patterns. OWN stores the kit and the three instrument sounds per pattern. A pattern without its own sound initially adopts the one now playing. OWN does not store per-pattern mixer, send-effect or master settings.
  • Note channels: channel 10 plays/receives the drum pads by General MIDI assignments, channels 2–4 address instrument tracks, and incoming channel 1 plays the selected track. Local keys transmit on the instrument track's channel or drum channel 10. Chord mode does not expand incoming MIDI notes.
  • Browser MIDI: choose MIDI ports if the browser exposes Web MIDI; permit access if you want this feature, then choose the input and output explicitly. Sound does not require MIDI permission. If a port loops back into itself, clear the unused out port.

What stays saved and where it goes

Project, samples and user sounds are separate
DataWhen it is keptWhere it stays
ProjectTap SAVE. If playing, the project write waits for Stop.On the device, patterns, song, sounds, mixer, FX, master, modulation and SETUP use a two-copy project store to survive a write interruption. Browser keeps its own copy in site storage.
SamplesWhen recording/transfer completes; while playing, a recorded sample is finalized when you stop.Separate shared sample bank, not embedded in the project. Export an individual hardware sample as a WAV with the Mac companion if you need a separate copy.
User presets and kitsImmediately on releasing SAVE after choosing a user location, while stopped. While playing, the screen says STOP FIRST.Separate preset store. Tap SAVE as well to keep the edits in the current project.

Browser saves are local to the site and browser profile; another browser, private mode, storage cleanup or a reset can mean a different or empty project. The browser's Factory reset requires a second press and forgets its saved groovebox data. It is not an audio fix and cannot restore data once cleared. Copy session is for troubleshooting, not backup.

Versions: 0.4 and 0.5 read each other’s projects; both read 0.2 and 0.3 project data. Older projects gain default values for newer settings; generator state starts unset. After a 0.4 SAVE, older firmware cannot read the new project format and can show a fresh project if downgraded. Return to 0.4 or 0.5 to read the new format again. Builds before 0.2 are not supported for conversion.

FM-1 hardware installation and recovery

GhettoMachine is replacement firmware for the M-VAVE FM-1. Save before updating, because the install restarts the device. Once an fm1-base or Felucca-based firmware is present, the fm1-base USB-MIDI installer can send the built GhettoMachine .fwsc package. It writes changed 4 KiB firmware sectors, not the boot code. Projects and samples are separate from those writes.

Stock M-VAVE firmware needs a different first-install path: the documented build initially used an ESP32-S3 adapter with a backup and dry run before writing. The same hardware recovery path was used for stock firmware. Don't treat a stock FM-1 or a cut-off install as an ordinary USB update. Check the exact firmware and board before proceeding; see the technical overview and fm1-base documentation.

Troubleshoot the symptom in front of you

Fast checks before resetting anything
SymptomTry this first
Browser: buttons move, no soundChoose Switch on, then PLAY. Unmute the webpage and the tab/device; turn up MASTER a little. A visible counter and moving LCD meters indicate the engine is running even if output is muted. Try the standalone emulator page rather than an embedded view.
Browser: keyboard doesn't control the deviceFocus a panel control, and check Keyboard shortcuts. Browser text fields and other focused elements don't send the panel's letter shortcuts. On a phone, rotate sideways for a larger control panel.
A step disappeared while trying to adjust itOn STEPS, releasing a lit step without operating an adjustment clears it. Undo with EDIT + OCT−. Keep the step held or latched while turning the knob.
A track appears to play or edit the wrong patternCheck the HOME row and its queued clip, not just the top pattern number. Choose BAR, BEAT or NOW on SONG as needed. Check whether SONG or a follow action is marking the next change.
Notes drop from poly chordsCheck for MONO mode, then POLY voice count and total voices on HOME. Shorten release or reduce overlapping notes/unison; the instrument tracks share a 16-voice pool, and the hardware can drop voices under load instead of breaking up.
No delay while sampling or holding an effectSampling, Stutter and Tape Stop borrow delay memory. Finish the sample or release the effect before changing send settings.
BANK FULL or a sample is shorter than the WAVCheck the shared bank, not just the selected track. Export and delete an unwanted hardware sample if appropriate, shorten the recording or use 22.05 kHz. STORED, CUT is a successful shortened sample.
MIDI clock doesn't start or notes doubleCheck SEND versus FOLLOW and the selected ports. The FM-1 FOLLOW starts on the first clock after Start; transmission is over USB. Remove MIDI loops and make sure the receiving track's channel matches.
Edits vanish after refresh or power cycleSave again and stop the transport so the write completes. Browser profiles do not share project data and private mode may not persist it. Export important hardware samples individually.
