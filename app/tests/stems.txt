# GhettoMachine 0.5's USB stems: the master on USB audio inputs 1-2, then each track alone (the drums 3-4, T2 5-6, T3 7-8,
# T4 9-10), dry, before the master chain; the tracks' own levels set the USB mix, MASTER only the speaker and the
# headphones (plat_usb_audio_full).  tools/build.py ../../app --host, then
#   app/build/host/ghettomachine_host app/tests/stems.txt OUTDIR   (the USB input's 10 channels in stems.wav)
# stems: the stems written this block (the host takes them always); stemN / stemNl / stemNr: track N's stem's peak since
# the last look (both sides, or one), dB x 10, -1200 silent; stemreset: every stem's peak started again; stemovers: stem
# samples clipped since the last look; peak_db_min / _max: the FM-1's own output (after MASTER) since peakreset;
# pkl / pkr: each side of the app's render (what the USB master pair takes) since the last look, dB x 10, -1000 silent
expect demode_0 1                 # (the stock 808 / 909: the DrumEngine has its own suites)
wait 600
master 4096
expect stems 1
expect usb_audio_full 1
usbwav stems.wav
# ---- stopped: every stem silent
wait 300
expect stem1 -1200
expect stem2 -1200
expect stem3 -1200
expect stem4 -1200
# ---- PLAY: the default beat, on the drums' stem alone (T2..T4 have no notes yet), centred
tap PLAY
wait 2000
expect stem1l >-200
expect stem1r >-200
expect stem2 -1200
expect stem3 -1200
expect stem4 -1200

expect pkr >-1001
